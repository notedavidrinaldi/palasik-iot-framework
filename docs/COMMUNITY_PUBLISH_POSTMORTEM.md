# Post-Mortem Publish Komunitas (30 Menit)

Gunakan halaman ini sebagai ringkasan cepat setelah paket komunitas dipublikasikan.

## 1) Snapshot saat publikasi

- Tanggal publish: `YYYY-MM-DD`
- Waktu mulai: `HH:MM`
- Penanggung jawab: `@username`
- Jalur eksekusi: `manual` / `otomatis` / `campuran`

## 2) Tanda tangan kelayakan teknis

- [ ] Sidebar wiki memuat item Good First Issues dan Issue Batch Cepat.
- [ ] Script `setup-community-labels.sh` berhasil dijalankan.
- [ ] Script `bootstrap-good-first-issues.sh` berhasil dijalankan atau issue disiapkan manual.
- [ ] 10 issue target sudah terdaftar.
- [ ] Label `good first issue` terpasang pada seluruh issue pemula.
- [ ] Link dokumentasi yang baru (docs + wiki) mengarah ke halaman yang benar.
- [ ] Checklist siap publish di `docs/PUBLISH_PACKAGE_READINESS.md` telah dicentang.

## 3) Output 30 menit pertama

- [ ] Jumlah issue baru yang masuk: `__`
- [ ] Jumlah diskusi baru: `__`
- [ ] Response pertama ke pertanyaan komunitas: `__` menit
- [ ] Diskusi yang dipin: `__`
- [ ] Kontributor pertama yang merespons: `__`

## 4) Masalah yang muncul

- [ ] Tidak ada masalah kritis pada publikasi.
- [ ] Jika ada, catat permasalahan dan tindakan:

```text
- Masalah:
- Dampak:
- Tindakan sementara:
- Rencana perbaikan permanen:
```

## 5) Tindak lanjut 24 jam

- [ ] Follow-up issue #1:
- [ ] Follow-up thread diskusi #1:
- [ ] Update checklist komunitas (kalender mingguan):
- [ ] Snapshot dokumentasi final (screenshot PR/notes) disimpan.

## 6) Template siap tempel (laporan singkat)

```md
## Ringkas post-mortem
- Publish: YYYY-MM-DD HH:MM
- Jalur: manual/otomatis
- Issue yang berhasil dibuat: 10/10
- Status label: good first issue ✅ / ❌

### Temuan
- Respons pertama: XX menit
- Kendala: -
- Perlu tindakan: -

### Next action 24h
- 1) 
- 2) 
- 3) 
```
