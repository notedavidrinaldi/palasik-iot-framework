# Template Announcement Komunitas

Gunakan template ini untuk mengumumkan paket Good First Issues PALASIK.

## 1) Template Pengumuman Utama (untuk GitHub Discussions / README Update)

Judul: `🎉 PALASIK Community Boost: Paket Good First Issues siap dipakai`

```md
Halo komunitas PALASIK 👋

Kami baru saja menyiapkan paket onboarding kontribusi baru untuk mempercepat partisipasi pemula:

- ✅ 10 issue Good First Issues (siap dikerjakan)
- ✅ Paket label komunitas (`good first issue`, `area:docs`, dan label lain siap pakai)
- ✅ Script bootstrap otomatis untuk membuat issue massal
- ✅ Checklist publikasi + post-mortem 30 menit

Buat Anda yang baru mulai, ini jalur termudahnya:
1. Buka docs: Good First Issues (list 10 tugas)
2. Pilih issue yang paling cocok
3. Buat PR kecil sesuai scope

Cara cepat mulai:
- [docs/GOOD_FIRST_ISSUES.md](GOOD_FIRST_ISSUES.md)
- [docs/GOOD_FIRST_ISSUES_BATCH.md](GOOD_FIRST_ISSUES_BATCH.md)
- [docs/CREATE_10_ISSUES_FAST.md](CREATE_10_ISSUES_FAST.md)
- [Contributing](../CONTRIBUTING.md)

Jika Anda maintainer, checklist siap publish ada di:
- [docs/PUBLISH_PACKAGE_READINESS.md](PUBLISH_PACKAGE_READINESS.md)
- [docs/CHECKLIST_COMMUNITY_BOOTSTRAP.md](CHECKLIST_COMMUNITY_BOOTSTRAP.md)

Kami tunggu kontribusi pertama Anda! 🚀
```

## 2) Template Ringkas (untuk Discord/Telegram/WA)

```text
[ANNOUNCE] PALASIK community onboarding sudah dibuka:
- 10 Good First Issues siap dikerjakan
- Label sudah di-seed (`good first issue`, `area:docs`)
- Ada panduan cepat posting issue + template untuk pemula

Mulai sekarang:
1) Buka docs/GOOD_FIRST_ISSUES.md
2) Pilih tugas sesuai comfort level
3) Buat PR kecil + share hasilnya

Link: https://github.com/notedavidrinaldi/palasik-iot-framework/blob/main/docs/GOOD_FIRST_ISSUES.md
```

## 3) Checklist posting announcement

- [ ] Judul jelas dan ringkas
- [ ] Tautan ke daftar issue dan docs sudah benar
- [ ] Sertakan call-to-action kontribusi pertama
- [ ] Sertakan kontak diskusi (GitHub Discussions)
- [ ] Catat tanggal & channel publikasi di post-mortem
