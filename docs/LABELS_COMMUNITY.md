# Label Komunitas PALASIK

Tujuan: membuat issue/discussion lebih mudah dipilah dan ditangani.

## Daftar Label Awal (7)

- `good first issue`
  - Warna: `8FEECE`
  - Fokus: tugas sangat sederhana untuk kontributor pertama
  - Penggunaan: cocok untuk dokumentasi kecil, typo, atau test kecil

- `help wanted`
  - Warna: `0E8A16`
  - Fokus: butuh bantuan komunitas
  - Penggunaan: issue yang sengaja dibuka untuk kontribusi publik

- `question`
  - Warna: `D876E3`
  - Fokus: pertanyaan operasional/clarification
  - Penggunaan: jawaban bukan di PR, tapi diskusi atau issue

- `area:docs`
  - Warna: `A2EEEF`
  - Fokus: dokumentasi, tutorial, contoh
  - Penggunaan: update README/wiki/docs markdown

- `area:plugin`
  - Warna: `FBCA04`
  - Fokus: pengembangan plugin
  - Penggunaan: issue atau PR yang menambah/ubah plugin

- `area:policy`
  - Warna: `D4C5F9`
  - Fokus: Trust/Policy engine
  - Penggunaan: bug/rencana terkait aturan kebijakan

- `discussion-needed`
  - Warna: `5319E7`
  - Fokus: butuh klarifikasi desain di diskusi
  - Penggunaan: issue yang hasilnya tergantung diskusi komunitas

## Cara pasang cepat (manual)

1. Buka halaman `Settings -> Labels` repo.
2. Tambahkan label sesuai daftar di atas.
3. Jika sudah ada warna serupa, pertahankan.
