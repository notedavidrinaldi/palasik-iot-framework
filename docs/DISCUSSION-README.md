# Pedoman Diskusi PALASIK

Agar komunitas tetap produktif, gunakan jalur berikut:

- **Q&A**: pertanyaan langsung cara pakai, error, setup.
- **Ideas**: usulan fitur/use-case baru.
- **Show and tell**: share use-case sukses.
- **Announcements**: pengumuman resmi dari maintainer.

Mulai dari yang kecil:
1. Baca [DISCUSSION-THREADS-READY-TO-POST.md](../wiki-content/DISCUSSION-THREADS-READY-TO-POST.md) untuk draft post.
2. Gunakan format yang konsisten: konteks, error, langkah reproduksi, dan harapan hasil.
3. Kalau Anda pemula, mulai dari thread `How to start` (Q&A) dan mention environment + output command.

Tujuan bersama:
- orang baru cepat berhasil menjalankan simulasi
- kontribusi jadi lebih jelas
- use-case komunitas bisa dipakai ulang
