# Cara Publish ke GitHub Wiki (manual)

Karena akses push ke `.wiki.git` belum tersedia di sesi ini, gunakan langkah ini:

1. Buka halaman Wiki repo: https://github.com/notedavidrinaldi/palasik-iot-framework/wiki
2. Klik `Create the first page` (atau `Edit`) lalu isi konten dari file di bawah.
3. Buat halaman sesuai nama file (tanpa ekstensi `.md`):
   - Home → `Home`
   - Ringkasan PALASIK → `Rangkuman-PALASIK`
   - Memulai PALASIK → `Memulai-PALASIK`
   - Arsitektur → `Arsitektur`
   - Trust Engine → `Trust-Engine`
   - Policy Engine → `Policy-Engine`
   - Runbook Operasional → `Runbook-Operasional`
   - Konfigurasi → `Konfigurasi`
   - Ringkasan Eksekutif → `Rangkuman-Eksekutif`
   - Ringkasan Bisnis → `Rangkuman-Bisnis`
   - Untuk Tim Non-Teknis → `Untuk-Tim-Non-Teknis`
   - Sitasi → `Sitasi`
4. Tempel isi file masing-masing ke halaman.
5. Simpan (`Save Page`).

Catatan: `_Sidebar.md` adalah navigasi sidebar di wiki untuk memperlihatkan daftar halaman.
