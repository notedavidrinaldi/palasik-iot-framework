# Good First Issues

Mulai berkontribusi dengan cepat lewat daftar berikut (pakai label `good first issue`):

- [ ] Perbaiki typo + konsistensi istilah di README/docs
- [ ] Tambahkan contoh `event.json` simulasi
- [ ] Tambahkan contoh output `status`
- [ ] Buat cheat sheet command operasi
- [ ] Tambahkan troubleshooting umum
- [ ] Tambah dokumentasi MQTT adapter
- [ ] Tambahkan badge komunitas di README
- [ ] Rapikan checklist docs/GROWTH.md
- [ ] Buat template kontribusi dokumentasi
- [ ] Audit link rusak docs

Lihat detil lengkap dan template issue di:
[docs/GOOD_FIRST_ISSUES.md](https://github.com/notedavidrinaldi/palasik-iot-framework/blob/main/docs/GOOD_FIRST_ISSUES.md)
