# Berkontribusi di PALASIK

Terima kasih sudah tertarik membantu! Semakin banyak kontribusi, semakin cepat PALASIK berkembang.

## Cara tercepat mulai berkontribusi

1. Baca [repo README](https://github.com/notedavidrinaldi/palasik-iot-framework#readme) untuk gambaran besar.
2. Pilih area kontribusi:
   - Dokumentasi: perbaiki tulisan, tambah contoh.
   - Kode: tambah plugin, adapter, atau policy logic.
   - Eksperimen: tambah dataset/skrip evaluasi.
   - Bug & issue: reproduksi, buat minimal case, sertakan log.

## 10 menit kontribusi pertama

- Fork repo.
- Buat branch: `feat/nama-fitur`.
- Ikuti alur standar: ubah → test → PR.
- Tambahkan minimal dokumentasi untuk fitur baru.

## Standar kontribusi

- Uji dengan `pytest` sebelum PR.
- Pertahankan kompatibilitas API inti.
- Sertakan contoh penggunaan jika ada perubahan perilaku.

## Template kontribusi cepat

- Judul PR jelas dan ringkas.
- Sebutkan: apa masalah, apa solusi, bagaimana cara testing.
- Cantumkan referensi issue jika ada.

## Butuh bantuan?

- Buka issue untuk diskusi desain.
- Buat eksperimen kecil dulu sebelum fitur besar.
- Dokumentasikan asumsi Anda di deskripsi PR.

## Arah pengembangan komunitas

- Tambah plugin siap pakai untuk kasus industri.
- Buat contoh edge-case yang memperkuat reliabilitas.
- Buat materi edukasi agar lebih banyak orang mudah mencoba.
