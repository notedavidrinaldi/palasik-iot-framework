# Strategi Komunitas PALASIK

Tujuan halaman ini: mempercepat adopsi dan kontribusi.

## Paket Aksi Cepat

- Tingkatkan onboarding: Home -> Cara Menggunakan -> Memulai.
- Aktifkan issue template (bug/fitur/docs) agar laporan dan permintaan lebih terarah.
- Tandai issue dengan `good first issue` untuk kontributor baru.
- Tampilkan call-to-action: star, fork, laporkan 1 issue, kirim 1 PR kecil.

## Kanal kontribusi

- Kode: plugin, adapter, policy/rules
- Dokumentasi: use case, contoh konfigurasi
- Riset: eksperimen trust-policy

## KPI yang mudah dipantau

- jumlah star repo
- jumlah PR baru per bulan
- jumlah issue valid
- kontribusi dari user baru

## Target

Semakin cepat orang berhasil menjalankan simulasi awal, semakin besar peluang mereka balik kontribusi.
